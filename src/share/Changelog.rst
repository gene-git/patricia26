* 2026-07-27  : **0.9.0**

.. code-block:: text

              - Initial Release
                *patricia26* has two components: A Patricia Trie library and a Python
                module using the library. It provides:
            
                * a modern C23 compliant (Linux) version of the the original C-code.
                * a Python module generated using Cython that uses the shared c-library.
                * an autogenerated API reference guide for both the C and Python code.
